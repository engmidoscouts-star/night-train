# Starlight Express — Night Train V5

A free, romantic, interactive 3D train built with **Three.js** and hosted on **GitHub Pages**.

**Live site:** https://engmidoscouts-star.github.io/night-train/

## Experience

- Cinematic exterior of a fantasy steam locomotive and four golden-trimmed sleeper carriages
- Moonlight, stars, smoke, decorated wheels and glowing station lanterns
- Enter the train to freely explore a decorated corridor, arched windows and velvet seats
- Find eight interactive framed memories and read their messages
- Responsive desktop and mobile controls

## Controls

- Outside: drag to rotate the camera; choose **Enter the train** to board.
- Inside, desktop: `W A S D` or arrow keys to move; drag to look; click a memory or press `E` when close; `Esc` closes the memory.
- Inside, mobile: on-screen movement and turn controls; tap a memory to open it.
- **Back outside** returns to the train exterior.

## Structure

- `index.html`: user interface and interactive train exploration
- `graphics-v5.js`: procedural geometry, materials, lighting, scenery, and interior decoration

No private photos or messages have been published. The images inside are placeholder artwork. Replace them with your own content when ready.

Dependencies: Three.js ESM loaded from jsDelivr; browser must be connected to the internet.
